# Common cryptographic functionality

* **proof**: module implementing zero-knowledge functionality
* **ciphersuite**: trait for the serialization of [Frost ciphersuite](https://datatracker.ietf.org/doc/html/rfc9591#name-ciphersuites)
* **commit**: commitment structure
* **hash**: hash output structure
* **polynomials**: functions for working with polynomials
* **random**: structure to obtain random values
