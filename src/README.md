# Module implementing threshold signatures

* **crypto**: common zero-knowledge functionality
* **ecdsa**: implementation of several variants of threshold signatures schemes
  based on ECDSA
* **eddsa**: implementation of a threshold signature scheme based on edDSA
* **protocol**: internal utilities to construct protocols
* **echo_broadcast**: broadcast protocol implementation, TODO: ask on what is it based?
* **generic_dkg**: generic Distributed key generation (DKG) functionality
* **participants**: global information on the participants of a protocol
* **serde**: serde serialization helper functions
